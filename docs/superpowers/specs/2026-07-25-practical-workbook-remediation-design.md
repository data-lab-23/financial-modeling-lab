# Practical Workbook Remediation Design

## Goal

東都精密工業の受領資料パックと完成三表モデルを、2026年3月期から2030年3月期まで数式連動し、財務三表と補助計算の差額を自動検知できる実務教材へ修正する。

## Scope

- 完成三表モデルの売上高、原価、人員、運転資本、固定資産、借入金、PL、BS、CF、出力を5年間展開する。
- BS、CF・BS現預金、固定資産、借入金、前提根拠、Critical指摘を数式で確認する。
- 貸借差額を現預金やその他資産へ強制的に入れず、CFから算出した現預金でBSを一致させる。
- 受領資料へ完全な残高試算表、勘定科目対応表、資料差異と調整方針を追加する。
- ダウンロードページに、5年連動、数式チェック、Excel再計算時の留意点を明記する。

## Model Architecture

計算順序は、前提条件 → 売上高・人員・原価・固定資産 → PL → 運転資本 → CF → 必要借入 → BSとする。支払利息は期首借入金に金利を乗じ、最低現預金を下回る場合のみ新規借入を行うことで循環参照を避ける。利益剰余金は前期末残高に当期純利益を加算し、配当は本教材ではゼロとする。

## Quality Controls

- 予測5列の主要計算行に数式が存在する。
- 各年度の資産合計と負債・純資産合計の差額がゼロである。
- CF期末現預金とBS現預金の差額がゼロである。
- 固定資産と借入金の期首＋増減＝期末がゼロである。
- チェック結果と提出可否は固定値ではなく数式で判定する。
- 数式キャッシュ値とJavaScriptで再計算した期待値を一致させる。

## Presentation

最初のシートで「計算整合性」と「意思決定への利用可否」を分ける。計算が合っていても、教育用の架空案件であり、重要前提の根拠確認が必要なため、意思決定への利用可否は「教育用・実案件への利用不可」と表示する。
